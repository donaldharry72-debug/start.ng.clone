# Start.ng clone

A static reproduction of the Start.ng homepage with the logo-style play icon hop on the primary button.

## Deploy on Vercel

Import this repository in Vercel and set the project root to `vercel-startng` if this folder is inside a larger repository. No build command is needed; Vercel serves `index.html` directly. The included rewrite keeps the page available on nested routes.

The page uses `startng-clone.css` and `favicon.svg` from this folder. Keep them beside `index.html`.
